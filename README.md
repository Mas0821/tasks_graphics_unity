This repository contains my practice project.

## Project Status: Work in Progress (WIP)

This is an early prototype created within a short timeframe. The primary goal was to quickly implement and test the required mechanics rather than focus on clean architecture.

## Features Implemented

- Script-driven animation (automated looping and keyboard input control).
- Physics interaction scene with multiple objects configured with Colliders, Rigidbodies, and Physics Materials.

## Known Issues & Future Work

- **Camera Script (`CameraDirection`):** The camera movement is currently unstable/jittery. I have an optimization plan for this but haven't implemented it yet.
- **Code Architecture:** The codebase is currently a bit messy and not refactored. Plan to clean it up and abstract the components properly soon.
- **Shaders:** I plan to add a custom shader (possibly rewritten in HLSL) into this project in the near future.
